##  About The Project

**Dodge the Beat** is a fast-paced, music-driven 4-lane arcade runner game that converts any uploaded photo into a playable game avatar, custom obstacles, soundtrack speeds, and game-over roasts—all powered by **Gemma 4**.

Instead of static AI image analysis, **Gemma 4** acts as a real-time creative game generator. Upload a photo (a selfie, your pet, or a campus landmark), and Gemma 4 extracts your character's vibe, generates 4 absurd physical obstacles to dodge, suggests matching music pace tiers (BPM), and delivers an unhinged game-over roast when you crash!

---

## ✨ Key Features

- 📸 **Vision-Driven Character Extraction:** Upload an image and let Gemma 4 parse your vibe and create an avatar sprite.
- 🎃 **Dynamic Absurd Obstacles:** Dodge items extracted from your image context (flying pumpkins, hot hostel beds, canteen samosas, or heavy textbooks).
- 🎵 **Music Pace Speed Engine:** Select your soundtrack vibe (Chill Synthwave, Campus Pop, or Chaotic Cyberpunk) to scale the obstacle movement speed (*Piano Tiles* style).
- 🕹️ **HTML5 Canvas Arcade Engine:** Responsive 4-lane lane-switching mechanics controlled via keyboard inputs (`A`/`D` or `Arrow Keys`).
- ⚡ **Gemma 4 Structured Generation:** Clean JSON schema responses ensuring zero prompt-parsing lag during gameplay.
- 💥 **AI Game-Over Roast:** Custom 1-liner roast generated by Gemma 4 whenever you hit an obstacle.

```
[ User Image Upload ] 
       │
       ▼
[ Frontend Compression ] ── (Downscaled Base64) ──► [ Express Backend Bridge ]
                                                            │

                                                   [ Gemma 4 Vision API ]
```

## 🚀 Quickstart & Setup Instructions

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher)
- A Google AI Studio API Key ([Get API Key](https://aistudio.google.com/))

### Installation Steps

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/your-username/tempo-panic.git
   cd tempo-panic
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env` file in the root directory:
   ```env
   GEMINI_API_KEY=your_actual_gemma_api_key_here
   PORT=3000
   ```

4. **Run the Application:**
   ```bash
   node server.js
   ```

5. **Play the Game:**
   Open your browser and navigate to `http://localhost:3000`.

## 🎮 How to Play

1. **Upload Photo:** Click **Choose File** and select an image (selfie, pet, campus object).
2. **Analyze with Gemma 4:** Click **Analyze with Gemma 4** to let the vision model process your vibe.
3. **Select Music Pace:** Choose a music speed tier (Easy Pace, Medium Pace, or Insane Speed) which sets the obstacle fall speed.
4. **Dodge & Survive:**
    - Use `Left Arrow` / `A` to move Left.
    - Use `Right Arrow` / `D` to move Right.
5. **Game Over:** If you collide with an obstacle, read your personalized Gemma 4 roast and click **Play Again**!
